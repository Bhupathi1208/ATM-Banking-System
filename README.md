ATM Console-Based Application                                                                                                                                                 
Project Overview:
The ATM Console-Based Application is a simple banking system developed using Python. This application simulates the basic functionalities of an Automated Teller Machine (ATM) through a command-line interface.
Users can securely log in using an account number and PIN, perform banking operations, and view transaction details. The project demonstrates concepts such as functions, conditional statements, loops, file handling, and object-oriented programming.

Features:
User Authentication (Account Number & PIN),
Balance Inquiry,
Cash Deposit,
Cash Withdrawal,
Money Transfer,
Transaction History,
Logout / Exit Option,
Input Validation and Error Handling,
Technologies Used

Programming Language: Python

Interface: Console / Command Line
Concepts Used:
Loops
Conditional Statements
variables
operators
